## 1. 复现与修复

| 编号 | 修复前实际复现 | 本批修复与复测 |
| --- | --- | --- |
| S01 分类异常导致崩溃 | Q01 返回 SUCCESS 但 items=null，组件执行 map，触发 React 默认错误页 | 在分类响应边界校验集合与必要字段，非法集合进入“暂时无法加载本店商品”，可重新加载，不显示空店或 React 崩溃页；共用分类读取的首页正常 9 件回归通过 |
| S02 商品异常误报空店 | Q02 返回 items=[]、total=null，显示“本店暂时没有在售商品”和缺失计数 | 校验请求页码/每页 12、非负安全整数总数、has_more、商品流和本页行数一致性，以及本店归属、唯一 ID、卡片渲染字段/金额；非法响应拒绝展示，不转换为合法空集合 |
| S03 旧重试打断新输入 | 商品重试延迟期间以 Enter 提交新搜索；新结果正确，但完成时搜索输入失焦到“本店商品” | 焦点恢复按店铺/请求键绑定，新查询清除旧意图；服务商品流令牌更新 URL 时迁移当前意图；延迟旧请求不覆盖新结果或移动新查询焦点，连续失败和过期商品流重试仍可正确恢复 |
| S04 店铺失效残留旧信息 | Q05 首次成功，随后 Q02 返回 NOT_FOUND；旧店铺横幅和筛选留在商品错误上方 | Q02 的 NOT_FOUND / STORE_DISABLED 只补一次 Q05 重检；不可见则隐藏资料、筛选及商品，显示店铺不可见。重检网络失败显示可重读店铺错误并隐藏旧展示；重检仍可见保留商品错误，防止误判和循环 |

新增 `catalogValidation.ts` 维护上述公开查询边界；商品页校验用于本店查询，未顺带重写其他商品接口。店铺资料按既有字段类型及精确 ID 检查。校验不新增商家名称长度或展示价业务限制；D060 / P035 的商家自填展示价可以超出实际 SKU 价区间，已售罄参考卡片仍合法。标识的坏 URL 不作为资料读取失败，由现有首字回退处理。旧 HTML 原型、OpenAPI 0.5.2、依赖、后端与数据库均未改动。

## 3. 浏览器与临时 HTTP 验证

使用与本批源码一致的生产包。API 模式连接本机临时虚构公开 HTTP 样本，正常模式仍为原四家店、九件商品；异常仅由临时服务返回，不修改正式商品数据。共执行 20 类模式，记录如下。

| 场景 | 实际观察 |
| --- | --- |
| 非法成功响应 | Q01 items=null、Q02 total=null 均进入可重试商品错误；无 React 崩溃、错误计数或成功空店；混入他店商品时拒绝展示 |
| 店铺连续失败 | Q05 连续两次 503，键盘 Enter 重试；再次失败焦点留在“重新加载店铺”，第 3 次成功焦点回店名，随后正常读取本店 2 件商品 |
| 商品/分类连续失败 | Q02 与 Q01 分别连续两次 503，再次失败后仍可键盘重试；第 3 次成功回“本店商品”标题，2 件商品/4 个分类正常。响应附加含特殊字符的商品流令牌，URL 规范化后焦点仍正确 |
| 空店与无匹配 | 确认 total=0 后显示“本店暂时没有在售商品”；提交搜索显示“本店没有符合条件的商品”，清空留在原店铺。加载骨架及失败状态不误报为空 |
| 缺失/停用店铺 | 初始 Q05 404 或 STORE_DISABLED 时不显示资料、商品或筛选，也不发 Q02；保留受控商城返回路径 |
| 浏览中失效 | 初次 Q05 成功后 Q02 404，补查 Q05 404 后隐藏旧信息；补查 503 时显示通用可重读店铺错误，手动重读后恢复且焦点回店名 |
| 商品错误但店铺仍可见 | Q02 404、Q05 补查仍成功时保留商品错误，不显示空店。请求日志恰为 Q05 两次（含初次）、Q01 一次、Q02 一次，无自动循环 |
| 标识与长资料 | 坏标识 URL 回退“好”且商品仍可用；有效 SVG 标识正常加载。临时 200 字店名/约千字简介在 800×600 下换行，页面 scrollWidth=800；下滚后工具栏仍在窗口内可达，不据此新增数据长度规则 |
| 旧查询与切店竞态 | 商品重试中提交新搜索，搜索框焦点保持；慢查询延迟 2 秒后不覆盖新查询。店铺资料延迟 2 秒时切换小橙数码，旧响应不覆盖新店名/两件数码商品 |
| 商品流过期 | 第 2 页旧令牌返回 FEED_EXPIRED，键盘刷新后回第 1 页并清除旧令牌，保留关键词、价格与原商城返回上下文；读取成功焦点回结果标题 |
| 正常键盘 | 搜索输入 Tab 依次到“搜本店”“搜全站”，Shift+Tab 可返回；键盘 Enter 切价格升序后收纳盒在前、选中状态与焦点保留；反向价格区间提交后错误通过 aria-describedby 关联输入，URL 不变 |
| 正常链路/日志 | API 新会话与 mock 新会话未捕获 console warn/error；mock 店铺 2 件→商城 9 件→店铺 2 件正常，1280×900 无横向溢出。故障 HTTP/坏图预期错误和修复前 React 崩溃另记，未混作正常会话日志 |
