## 4. 2026-10-24 第 1 批缺陷修正

先核对“产品经理”对话中 D057 / D059 / D060 / D076 的确认内容及当前文档，再修正正式 React 首页。商家可选填展示价、每页 12 件、筛选与排序布局、尚未迁移入口跳转 HTML 原型，继续沿用原定范围。

- **价格重置**：清空输入时同步清除错误提示；商品流令牌写入 URL 时不重置用户尚未提交的价格输入。
- **商品价格**：保留 MERCHANT 的展示价原值，避免用实际 SKU 价差给商家展示价自动加“起”；AUTO 在售区间价格保留起价标识。未新增商家展示价标签、校验限制或筛选/排序业务规则，P035 继续待确认。
- **售罄**：契约返回 SOLD_OUT 时显示“已售罄 · 价格仅供参考”，保留详情查看；不新增加购、购买或详情实现。
- **稳定翻页**：保存并回传既有 feed_token，当前历史项使用替换写入，翻页、刷新和浏览器前后退沿用；改变筛选、排序或 page_size 时重建。FEED_EXPIRED 保留条件，从第一页获取新上下文，避免刷新动作先重试旧页。

已执行验证：

- 现有 5 项逻辑测试及新增 2 项商品流生命周期测试通过，共 7 项；新增覆盖不透明令牌的 URL 往返、前后页传递及筛选/排序/page_size 变化后的失效。
- TypeScript 检查、默认 mock 及 API 模式生产构建通过，使用现有锁定依赖，没有新增依赖。
- 1280×720 浏览器下，默认 mock 首页复现“100–20 元 → 应用 → 重置”，观察到输入和错误同时清除，货架恢复显示。
