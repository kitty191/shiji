# 拾集 · 草稿图片管理交付

日期：2026-10-28；基线 `07b0163`，D108。用户确认继续草稿图片管理小批。

## 1. 本批行为

- 从演示素材库选图、逐张/全部移除、前移/后移和设为主图；首图为主图，保存后 G03 恢复顺序及基本资料，私有商品列表缩略图随主图更新。图库选择只是未保存输入，不自动提交或发布。
- 九个独立虚构素材记录复用已有图片文件，以模拟店铺归属限定 PRODUCT_IMAGE / READY；素材库返回既有 M02 元数据字段，不返回私有归属字段。复用文件不是推定其他店铺真实资产可用。本轮不提供本机文件导入，不请求真实 M01/M02/M03 或 OSS，不实现素材删除/回收。
- G04 图片请求为完整顺序数组；省略 images 保留，[] 清空。已有图片 ID 保持，新图用 client_key 换取 IMAGE id_map；校验身份二选一、引用归属、ID/临时键不重复及素材资格，不接收任意 URL。请求数组顺序决定 sort_order / cover_image，图集、文字、版本和回执同次保存，不产生半保存。
- 同一回执重放返回首次图片映射，再读取最新草稿；不会重建图片 ID、回滚后来顺序，或因素材/分类后来不可用而重做完成的写入。旧无图 v1 快照及无映射回执继续读取，不清空已有浏览器草稿。已保存图片读取不依赖素材库当前列表，保护历史引用；仅改文字时省略图集，保留旧图。
- 素材库加载/失败/空态独立于表单；库失败不丢输入，绑定时素材失效会拒绝保存并保留文字与选择，移除/重选后可重试。坏图显示占位，不自动删除。选中素材按钮禁止重复点击，未将此扩大为 API 全局素材唯一或图库数量上限。
- 图片改动纳入未保存离开保护。添加、排序/设主图、移除后焦点回相应图片组；清空回素材标题。素材库连续失败后焦点回重试按钮，成功回素材标题。基本资料、版本冲突、未知结果锁定/原键恢复和已成功后只读沿用上一批。

SKU、已发布商品编辑、上下架、库存、真实认证、后端/数据库与素材回收未扩展。OpenAPI 0.5.2 结构已含以上契约，无新接口；依赖、旧 HTML 原型和原图片文件不变。

## 3. 浏览器检查

正常生产包与独立临时故障包分别检查。故障包只替换网关及素材可用性来源，实际页面、保存/回执及恢复逻辑一致；检查后正常网关已逐字节恢复。测试服务仅绑定本机。

| 场景 | 实际观察 |
| --- | --- |
| 旧数据兼容 | 同源预览先运行 D107 包，新建/保存无图草稿；切换本批包后刷新，仍同一 ID，标题/家居分类保留，图库为空且可选九个素材，无清空或重复创建 |
| 正常图集 | 选三张，键盘设第三张为主图，顺序为收纳盒/键盘/台灯；保存刷新顺序保持。前移保持对应图片、焦点回图片组；删主图后下张成为主图，保存后列表缩略图同步 |
| 清空与离开 | 只有图片改动也弹未保存离开提示，Escape 保留图集并回原返回入口；清空保存/刷新后图集 0、库仍 9，没有删除素材 |
| 双页编辑 | 第二页持旧版本添加图片，被拒绝覆盖，未保存图片仍保留且保存禁用；明确重读后采用另一页最新两张图片 |
| 素材库重试 | 连续两次失败，已填标题不丢、基本表单可用，第二次失败焦点留重试按钮；第三次成功显示九个素材并聚焦素材标题 |
| 保存失败/素材失效 | 两次明确失败后仍可改变主图再保存；素材失效拒绝整次图片保存，简介和顺序保留，移除失效项后成功 |
| 未知/只读恢复 | 写后响应丢失时添加/修改被锁定，原请求确认后图集不重复；已知成功后两次 G03 失败，日志为 save=1 / read=3，失败焦点留恢复按钮，成功显示新主图 |
| 空库与坏图 | 空素材库时已存两图保留，只保存简介后图集不变；坏 URL 保存并刷新仍保留三条引用、坏图显示占位，未误判为空图集 |
| 慢响应/边界 | 素材库延迟两秒时离开至列表，迟到响应没有重新显示图库；API 编辑页显示私有接口不可用，无演示图库回退；公开首页仍九件 |
| 排版与日志 | 1280×900/1320、800×600 所查页面无横向溢出；800 窗口图库宽 638、页面宽 800。正常 mock/API 新会话无 console warn/error；临时坏图的预期 404 单独记录，不混同正常日志 |

运行草稿、图片引用与回执均为虚构本机数据，不入 Git。没有测试真实账号切换、HTTP 素材上传/鉴权/回收、跨设备竞争或后端；图库资源损坏检查也不代表实现了素材生命周期服务。
