## 2. 已修复问题

### A01 / P2：公开商品异常响应可以进入渲染

原 `getProducts` 直接返回成功 data，`getProductView` 只查 view_status，推荐也直接返回；例如首页 items=null、详情 skus=null、推荐 items=null 均可触发渲染异常。店铺查询已有的结构检查未覆盖这些入口。

现在首页/店铺复用卡片和分页校验；详情校验路由目标、店铺、图集/维度/规格/参数数组的字段结构与必要标识；推荐校验集合和核对时间。非法成功数据进入现有错误/重试分支，不转为空列表。空的正常集合、真实越界页、坏图片 URL、售罄参考价、商家自填价在 SKU 区间之外、缺失图片绑定与不完整规格组合仍按原规则处理，不新增业务约束。空、点与双点商品 ID 在发起请求前拒绝，避免路径归一化读到其他资源。

### A02 / P2：安全整数金额转元展示丢失最后一分

原格式器将整数分除以 100 再交给浮点格式化；9007199254740991 分原显示为 90,071,992,547,409.9 元，丢失末位 1 分。价格筛选回填也存在同一转换问题。

新增共用 centsToYuan，先按整数分拆分元/小数，再格式化千分位，保留既有 59 / 29.9 视觉格式；筛选输入和草稿输入共用精确回填。没有降低允许金额上限或改变交易整数分规则。

### A03 / P3：商家订单越界难以恢复原查询

原第 999 页只有逐页返回或清空条件，缺少保留条件直达第一页。现增加“返回第一页”，保留状态、订单号与成交商品关键词；焦点意图绑定查询键，旧查询响应不能消费新查询的焦点，清空也沿统一更新入口。

### A04 / P3：公开商品卡片坏图缺少占位

原非空图片 URL 加载失败时保留浏览器损坏图标。现卡片显示“暂无商品图片”，图片 URL 更新后重新尝试；详情/店铺入口和价格照常可用，不删除图片引用。

### A05 / P2：订单联查重读后仍可能显示不一致版本

原 loadOrderDetail 检测订单/支付单差异后只重读订单一次，没有确认重读结果是否已匹配。通过受控旧快照可复现该方法返回互相矛盾的状态，或把不同支付单/订单身份配对。

现在最多重读订单一次，再核对订单 ID、支付单 ID、支付状态及本单摘要状态；仍不一致则进入现有错误重试，不显示混合快照、不无限重读。新增两项用例修复前均为 Missing expected rejection，修复后通过；既有发货、收货和超时发生在两次读取之间的用例继续通过。

浏览器使用独立本机端口与虚构资料，实际操作：

1. 首页 20–60 元筛选后进入台灯详情；默认白色 USB、售罄选择、图集和实际规格价核对。正常公开货架仍 9 件。
2. 加购到完整购物车，数量改为 2、删除后在 8 秒内撤销，恢复 2 件及 118 元；另观察超过 8 秒后撤销入口消失，不将时限当作故障。
3. 从结算进入地址管理，新建首条自动默认、编辑原地址回显、第二条独立设默认；删除第二条默认地址后，结算选择器只剩第一条并带默认标识、原编辑内容保留。
4. CART 提交 118 元订单→模拟付款→付款结果→商家订单→填写虚构物流发货→买家确认收货，订单完成、金额/收货信息/物流与首次收货时间正常。最终包再次打开该已完成详情，支付单和本单状态一致。
5. 商家待发货订单带成交关键词访问第 999 页，“返回第一页”后筛选保留，并可进入本单详情。
6. 草稿选择两张图、设置第二张为主图、保存/重新打开保持顺序；90071992547409.91 元保存后列表显示完整 .91、刷新输入仍精确。标题在编辑页实际保存/刷新回显；未保存简介离开弹窗选择继续后输入保留。
7. 本机公开 HTTP 样本依次返回非法首页 items、非法详情 skus 和非法推荐 items；均显示各自错误/重试分支，恢复合法数据后分别得到 9 件商品、正常详情和 2 件推荐。坏图样本显示占位；样本不是 Java 服务。
8. 800×600 与默认 1280 桌面窗口检查首页、详情、商家表格/草稿图集、订单、结算/付款所查状态。所测页面 scrollWidth 与 innerWidth 相同；800 宽下商品表格容器 680px、草稿图集 638px，表格可局部横向滚动，未发现页面级横向溢出。另在最终包从本店搜索台灯、立即购买 59 元并取消待付款，关闭状态/提示正常。
9. 正常 mock 会话、新会话最终包的 console warn/error 均为空；公开异常结构样本无渲染崩溃日志。坏图 404 属于注入样本预期资源错误，不混同正常日志。

浏览器权限审查曾超时，用户明确同意继续后恢复；中途额度恢复重启了临时服务，最终构建已重新连接并检查。未绕过浏览器权限，不把工具超时当成项目缺陷。测试用临时服务、数据、构建、截图与编译比较脚本均不入库。
