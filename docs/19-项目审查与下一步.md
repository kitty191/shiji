## 2. 审查发现

### R01：测试命令与声明的最低 Node 版本不一致（P2，待处理）

[package.json](../frontend/package.json) 声明 Node >=22.12.0，但 npm test 为 node --test tests/*.test.mjs；测试直接导入 src 中的 .ts 文件。Node 22.12 需要显式启用 --experimental-strip-types，当前命令不能覆盖声明的全部版本范围。依据为 [Node 22.12 官方 TypeScript 文档](https://nodejs.org/download/release/v22.12.0/docs/api/typescript.html#type-stripping)。

本机 Node 26.7.0 的正常 npm test 通过；在本机关闭类型剥离后，测试出现 ERR_UNKNOWN_FILE_EXTENSION，确认测试依赖该能力。这是机制验证，没有安装或实际运行 Node 22.12。本轮未改依赖/测试命令；后续建议对齐 Node 要求和测试运行方式，并用选定最低版本验证。不影响当前本机继续开发。

### R02：当前状态文档混入旧阶段结论（P2，本轮已修正）

开发路线、环境说明和维护表仍把“工程未创建”“前端暂停”“尚无提交”放在当前状态。已更新当前入口、阶段表及 AGENTS 的概括，旧 D072 / D075 过程继续标为历史，不删除原决策。第 1 批进度、实际实现和已交付记录保持一致；README 按 D078 不增加内部过程说明。

### 后续实施准备，不属于现有首页缺陷

- **详情默认规格**仍待确认。ProductDetail 已预留 default_sku_id，但字段存在不等于自动选择规则已获采纳；进入自动选择实现前需确定行为。
