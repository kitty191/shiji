## 1. 已实现

- 正式 `/merchant/products` 路由和头像菜单“店铺商品”，保留商家中心入驻原型；页面提供本店商品/店铺订单导航，不提前放入编辑、发布或库存写入入口。沿用现有桌面表格与筛选样式，新页面按路由加载。
- G01 摘要字段：商品标题、主图、销售/平台状态、展示价、SKU 数量、可售库存、更新时间。销售状态为在售/已下架/草稿；平台限制与库存为零单独提示，售罄不转换为下架。标题/主图/价格缺失可显示未命名/暂无图片/待完善，价格 0 仍显示金额。
- 名称与销售状态组合查询，每页 12 件，条件改变回第一页；URL 保存关键词/销售状态/页码，清空保持本店，支持刷新/前后退和越界直返第一页。更新时间降序、同时间按商品 ID 稳定排序，未新增用户排序控件或修改公开列表算法。
- 绑定既有固定演示店铺 store_home / 好物生活馆。数据层先按精确归属限定，再筛选、计数和分页；不从网址或额外 query 字段接收归属，UI 固定每页 12，查询层按 G01 允许 1–50 的有效容量。返回仅有 G01 白名单字段，不暴露完整 SKU/编辑内容。
- 只读模拟源适配原有商品详情和交易账本计算的当前可售库存，列表读取不写商品、订单、购物车或库存。当前本店仍只有台灯与收纳盒，未永久新增草稿/下架记录；所有商品尚未编辑，摘要更新时间沿用首次发布时间，只读模拟 edit_token 不用于保存或真实冲突校验。后续编辑批次再接完整商家数据模型。
- 资料损坏或读取失败不转换为空列表，提供重试；重试的焦点意图按查询绑定，新查询不受旧响应或旧焦点影响。API 模式明确提示商家商品接口暂不可用，不发送未认证的私有读取，也不回退本机模拟商品。

不变更 D060/P035：展示价不限制在 SKU 实际价区间，交易仍按 SKU 计价。未修改 OpenAPI 0.5.2、旧 HTML 原型、依赖、Java 后端、数据库或 Agent。
