# 拾集 · 付款结果页交付

日期：2026-10-25；基线 160fd2c，D098。本轮先推送原有格式整理，再推进此前约定的独立付款结果页。

## 1. 本批实现

- 新增 `/payments/:paymentId/result`，只通过 T03 重新读取当前支付单。PAID 显示模拟成功、总金额、付款时间与关联店铺订单；PENDING 显示尚未完成并提供返回付款页；CLOSED 区分取消与超时。网址的 success/status 参数不参与结果判断。
- 正常付款完成后替换当前付款路由进入结果页；确认未知付款后也进入结果页。提交订单和确认取消仍进入原付款页。付款页为已付/关闭记录提供结果入口。
- 加载、读取失败/重试、缺失记录及 API 不可用有对应反馈；失败只重读，不在访问、刷新或重试结果时付款。连续读取失败后焦点回重试，恢复后回结果标题。
- 待付款结果在截止后重新核对一次，采用查询响应，不自动长期轮询或从本机时钟推断最终成功/关闭。
- 显示关联店铺的订单号、状态及合计，提供查看订单详情、我的订单、支付单或继续商城。原详情/列表筛选和页码按既有白名单保留，结果路径不能成为循环返回目的地。

页面沿用既有桌面布局和样式，没有修改模拟交易引擎、库存/快照/期限规则、OpenAPI 0.5.2、依赖/锁文件、HTML 原型或后端。
