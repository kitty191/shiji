# 拾集 · 商家商品草稿首批交付

日期：2026-10-27；基线 `199bb8d`，D107。按用户“可以，下一步”推进新增/编辑草稿，保存后回显同一商品。

## 1. 已实现与范围

- 列表新增“新增商品草稿”，只在主动点击时创建持久空草稿，进入 `/merchant/products/:productId/edit`；刷新、重开、前后退和编辑入口只读取已保存记录，不重复执行创建。草稿行提供编辑入口并保留列表查询/页码，已在售商品不开放本批编辑。
- G02/G03/G04 的前端模拟：名称、分类、简介、可选展示价；资料可暂缺。省略字段保持、显式 null 清空，金额 0 与未填分开，输入转为整数分；填写的分类 ID 须可用，展示价不要求处于 SKU 区间。保存保持 product_id / created_at / DRAFT / published_at=null，更新 edit_token / updated_at；不发布、不创建图片/SKU/库存。
- 草稿及回执独立保存在本浏览器，快照损坏或存储失败保持错误，不用空集合覆盖旧数据。私有列表合并原本店商品与已保存草稿，继续按绑定店铺过滤/查询/分页，只投影 G01 摘要；公开首页仍原九件，订单/购物车/原库存不变。当前草稿模型仅含基本资料及空图片/规格集合，后续扩展需同步模型。
- 读取和保存按同一 ID；旧 edit_token 冲突拒绝覆盖，当前输入保留，用户点击“重新读取并替换当前输入”后再编辑。创建/保存回执与草稿同次写入，原键重试不重复创建或覆盖后来修改；命中首次回执后再 G03 读取最新内容。
- 创建与保存共用单次在途状态。明确失败可修改输入重试；结果未知保留原目标/载荷/键，禁止新写，站内返回商品管理可继续确认。已知写成功但读取失败只重读；连续失败后焦点回恢复按钮，成功回编辑保存按钮或已保存草稿入口。未知结果为前端协调状态，没有新增 API 返回码。
- 站内导航与刷新离开时，未保存或待确认状态提供保护；在途不能确认离开。取消/Escape 继续编辑，确认离开丢弃未保存输入，已保存草稿保留。操作标记/未保存输入不承诺跨刷新、关闭、账号切换或设备恢复。
- API 模式明确接口未接入，不发送未经认证的 G02/G03/G04 或回退模拟。仍固定本机虚构商家上下文，不代表服务端鉴权、跨浏览器存储竞争或数据库事务验收。

图片、SKU、已发布商品编辑、发布/上下架、库存调整、真实后端/认证/数据库和 Agent 均不在本批；OpenAPI 0.5.2、旧 HTML 原型与依赖不变。
