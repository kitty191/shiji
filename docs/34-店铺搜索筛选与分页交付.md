## 1. 本批行为

- 顶栏使用“搜索本店商品”与“搜本店”，另有“搜全站”按钮；全站搜索只带当前输入的关键词。本店搜索与分类、价格区间组合，保留本店结果数，支持综合、价格升降、最新上架排序，每页 12 件。
- Q02 参数包含固定路由店铺 ID、关键词/分类/整数分价格/排序/页码/每页 12 和服务返回的 feed_token。模拟层先按精确店铺 ID 限定，再筛选/排序/分页；调用者不能把店名、额外 store_id 或 page_size 改成本店归属或容量。沿用当前展示价口径，未采纳 P035 的新规则。
- 清空条件留在当前店铺并保留原商城返回上下文；新条件/排序重置第一页和商品流，翻页保留当前商品流。正常/无匹配/越界分别展示，越界可以保留条件直返第一页。
- 店铺 URL 保留全部受支持条件、页码、商品流及原商城上下文。店铺→商品详情→结算→返回时保留查询和浏览位置；同店入口保留条件，换店从默认条件开始。返回路径规范化也保留这些字段，不允许递归嵌套店铺或外部返回地址。
- 资料和商品结果分开加载，更新商品条件时保留店铺资料；旧结果不覆盖新查询。feed_token 过期时提示刷新，保留筛选并从第一页重取，重读焦点回结果标题/重试按钮。快速连续更改条件按最新路由状态处理。
- 首页与店铺提取共用分类/价格/排序/条件摘要控件，保持已有暖橙桌面布局和首页行为。未改旧 HTML 原型、接口结构、依赖或真实后端。
