# 拾集 · 前端代码规范

日期：2026-10-28；D109。适用于 frontend 中的正式 React 工程。

## 1. 格式约定

- 固定 Prettier 3.6.2 为开发依赖，由 package-lock.json 锁定，不依赖全局安装。
- 2 空格、UTF-8、LF 和文件末尾换行；JS/TS 单引号、100 字符目标行宽与标准尾逗号。长字符串等不能安全拆分的内容不强行截断。
- 源码、JSX、样式、测试、前端脚本和配置统一排版。不要为了减少行数将多个逻辑步骤或整段 JSX 手动压在一行；命名、必要注释与函数职责仍需人工审查。
- `.editorconfig` 提供通用编辑器约定；`frontend/.prettierrc.json` 与 `.prettierignore` 定义格式器行为。

## 2. 已核对的命令

在 frontend 目录执行：

```bash
npm run format
npm run format:check
npm run typecheck
npm test
npm run check
npm run build
```

`format` 会改写排版，`format:check` 只检查。`check` 顺序执行格式、类型和测试；任一失败返回非零。正式交付还应完成与变更相关的构建、浏览器及文档检查，不能把格式通过当作业务通过。

## 3. 范围和维护

包含 src 的 TypeScript/TSX/CSS、tests、scripts、前端 JSON 配置、index.html 与 frontend/README.md。忽略 node_modules、dist 开头的构建目录、public、assets、demo 以及自动生成的 package-lock.json。旧原型的 source/template/index 必须继续保持导出一致，不能只改一个生成文件的排版。共用 docs 不进行无关的全仓格式重写。

本次已整理全部 79 个 TS/TSX 源文件、样式、21 个现有测试、资源同步脚本及前端配置/说明。截图中 DraftImagesEditor.tsx 从 38 行展开为 218 行，组件入参、状态、异步处理和按钮 JSX 可逐段阅读。功能修复另行提交，便于审阅。

格式整理后原有 278 项测试与类型检查通过；还比较了 80 个 TS/TSX（包含 Vite 配置）的编译结果，71 个经统一排版后相同，其他 9 个仅为对象换行或等价相邻 JSX 文本节点拆分，已逐项核对。整体业务复核结果见 [前端整体复核](40-前端整体复核.md)。
