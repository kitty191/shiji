# 拾集 · 店铺基础页交付

日期：2026-10-26；基线 `625f1fd`，D103。用户确认店铺三步建议中的第一小批。

## 1. 本批实现

- 正式 `/stores/:storeId` 页面沿用现有桌面布局，展示名称、标识、简介与本店商品。标识为空或加载失败时回退店名首字；不增加关注、评分、销量或其他新界面功能。
- 复用 Q05 `PublicStore` 与 Q02 的 `store_id`，按精确 ID 取本店商品后分页；模拟资料与现有四家店/商品 ID 一致，简介沿用原型。商品卡片复用当前公开模拟报价和库存，不用店名搜索代替归属，不混入他店商品。API 返回混店数据时拒绝展示。
- 当前只显示默认顺序第一页、最多 12 件，保留本店总数；有更多记录时明确标注当前展示前几件。顶栏仍为全站搜索，本店搜索/筛选/排序/翻页下一小批，不放置无效控制。
- 首页/推荐卡片店铺来源、正常/下架商品详情、购物车退役规格的原店铺导航进入正式路由；购物车导航使用契约里的原目标 ID。店铺内卡片的店名为文本，避免重复进入同店。
- 店铺商品进入正式详情后显示“返回店铺”，保留原商城查询和浏览位置；深链接返回路径仅允许应用买家/购物车/店铺受控结构，店铺自身只携带买家上下文，拒绝任意地址与递归嵌套。沿用既有 SKU、数量、加购和购买流程。
- 具备基础加载、空列表、缺失/暂不可见、错误重读与重读焦点恢复；旧响应在换页/离开时清理。全面异常与键盘专项回归仍在第三小批。

本批都是公开只读查询与既有前端模拟，不创建店铺/认证/后端/数据库，不修改 OpenAPI 结构、旧 HTML 原型或依赖。
