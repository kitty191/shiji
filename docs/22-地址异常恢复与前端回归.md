# 地址异常恢复与前端回归

日期：2026-10-25。范围：D087 / 3A3，以已推送的默认地址提交 4718aab 为起点，核对收货地址列表、新增、编辑、独立默认设置及既有买家前端。此记录为模拟前端验证，不代表后端接口、认证或数据库验收。

## 1. 修复与恢复约定

| 情况 | 页面行为 | 重试规则 |
| --- | --- | --- |
| 地址列表读取失败 | 显示错误，不显示空地址簿假象；新增禁用 | “重新加载地址”只读列表 |
| 新增/编辑明确未写入 | 保留并允许纠正输入 | “重试保存地址”提交当前表单；取消并丢弃后清理旧重试意图 |
| 默认设置明确未写入 | 保留原已确认默认标记 | “重试默认设置”使用原目标 |
| 写入结果未知 | 保留原请求/操作键并锁定其他写入 | 确认原操作；禁止换内容重发，离开返回仍可确认 |
| 写入成功、列表读取失败 | 说明已保存并锁定进一步写入 | “重新读取地址列表”只读，不再次写入 |
| 编辑冲突 | 保留用户输入并禁用保存 | 明确重新载入；读失败显示错误，成功后才替换输入/版本 |

取消/站内导航时，未保存输入提示丢弃风险；待确认操作提示返回继续确认；已保存待刷新列表提示继续读取。确认离开不会清除共享状态中的待确认操作。保存进行中禁止确认离开。关闭编辑表单会使该表单的旧读取响应失效，不能据此重新打开旧表单。
