## 技术选择当前状态

用户此前询问 Python / FastAPI 和中间件接入能力，之后明确选择 **首版 Java / Spring，后续 Python**。当前所有商城开发以 Java 版为主线；Spring Boot 为默认实施建议，FastAPI 为后续 Python 框架候选。
