# 拾集 · shiji

拾集是一个多商家商城项目，面向买家购物、商家经营和平台管理等场景。

前端采用 React、TypeScript 和 Vite，界面以暖橙色与简洁的桌面布局呈现。

## 前端功能

- 商品搜索、分类与价格区间筛选。
- 商品详情、竖排图集、规格选择与价格库存查看。
- 综合、价格和最新上架排序。
- 筛选条件随地址保存，支持刷新与浏览器前后退。
- 详情加购、购物车摘要与独立购物车页面，支持按商品、店铺或全选并统计已选金额。
- 购物车数量调整、库存不足修正、单项/批量删除与 8 秒撤销。
- 模拟购物车商品与数量可在浏览器本地保存。
- 收货地址列表、新增与编辑，支持原内容回显、更新原地址及浏览器本地保存。
- 首条地址自动默认，支持将已有地址设为默认，始终最多保留一个默认地址。
- 地址保存失败可重试，未保存或待确认操作提供离开提示。
- 收货地址删除与失败重试；删除默认地址后自动设置剩余第一条，删完显示空地址簿。
- 购物车结算与详情立即购买，支持地址选择、按店铺预览费用及提交模拟订单。
- 订单列表、状态筛选、订单号查询与详情快照，支持取消整次待付款结算。
- 模拟订单可在浏览器本地保存；模拟付款与收货功能暂未开放。
- 右侧快捷工具栏收放与返回顶部。

## 本地运行

安装 Node.js 后，在项目根目录执行：

```bash
cd frontend
npm ci
npm run dev
```

打开 [本地预览](http://127.0.0.1:5173/#/buyer)。

在 frontend 目录中构建或运行测试：

```bash
npm run build
npm test
```
