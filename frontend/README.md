# 拾集前端

基于 React、TypeScript、Vite 和 React Router 构建的桌面端商城界面。

提供商品浏览、搜索、分类与价格筛选、排序、分页和快捷工具栏。商品卡片进入正式详情页，可查看图集、切换规格、调整数量并查看价格库存；刷新保留选择，返回列表保留条件与浏览位置。详情支持加入模拟购物车，右侧摘要按店铺展示原规格、数量与可购商品金额，页面间共享并在刷新后恢复。摘要中的“查看购物车”进入独立页面，支持按项、按店和全选可购商品，显示已选项数、件数、店数及金额；支持数量加减、库存不足时明确调低数量、单项和已选商品删除，以及 8 秒内撤销最近一次删除。数量为 1 时再减会删除该项。勾选在当前应用会话内保留，整页刷新后重新默认选中可购商品。头像菜单的“收货地址”进入正式地址页，可查看、新增与编辑虚构地址；编辑时回显原内容，保存更新同一条地址并保留默认状态。首条自动默认，后续新增可勾选切换默认，也可在已有地址卡片点击“设为默认”，切换后最多保留一个默认地址。地址卡片提供删除入口与确认弹窗，确认后移除本地模拟地址；删除默认地址时自动设置剩余列表第一条，删完为空地址簿。删除失败保留原地址并可重试，结果未知时确认原删除，删除已完成而列表读取失败时只重读。删除后自动显示最新列表；确认读空后显示空地址簿，可再次新增。读取中、失败或结果待确认不会显示为空地址簿。保存明确失败时可修改输入后重试，结果待确认或列表待刷新时提供对应操作；未保存输入、待确认操作离开前会提示，可选择继续填写或继续确认。

购物车“去结算”只带入已选可购商品；详情“立即购买”只结算当前 SKU 与数量。结算页支持默认地址回显、地址选择/管理与返回、分店商品与包邮费用、刷新预览及提交模拟订单。商品价格、库存、地址或所选购物车内容变化时需重新预览；数量操作待确认时不能提交购物车结算。提交成功后按店铺生成待付款订单并进入独立付款页，只移除本次选中的购物车项，立即购买保留购物车。

头像菜单“我的订单”提供状态筛选、订单号查询、分页及详情；订单保留提交时的商品、规格、成交金额和地址快照。待付款可确认取消整次结算，会关闭同一支付单下的全部店铺订单并释放占用的模拟库存，商品不会自动返回购物车。订单在本浏览器保存，超时状态在读取/刷新时核对。独立付款页展示支付单号、关联店铺订单及金额、总金额、创建/截止时间和倒计时，支持刷新状态和取消整次结算；订单详情提供付款页入口，返回保留订单与列表筛选上下文。倒计时结束后会重新核对状态；读取失败可重试，缺失支付单有返回入口。模拟付款按钮暂不可用，模拟付款与收货暂未开放。店铺、资料、消息、商家及管理台仍打开随附的 HTML 交互原型。

## 本地运行

在 frontend 目录执行：

```bash
npm ci
npm run dev
```

访问 [本地预览](http://127.0.0.1:5173/#/buyer)。Node.js 版本要求见 [package.json](package.json)。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| npm run dev | 启动开发服务 |
| npm run build | TypeScript 检查与生产构建 |
| npm test | 运行商品查询、SKU、库存、购物车、地址、结算与订单测试 |
| npm run preview | 预览生产构建 |

## 数据配置

默认使用本地模拟数据。将 [.env.example](.env.example) 复制为 .env.local 后，可以调整：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| VITE_DATA_SOURCE | mock | 设置为 api 时请求商品查询接口；购物车、地址、结算与订单暂不可用 |
| VITE_API_BASE_URL | /api/v1 | API 请求地址前缀 |

模拟购物车仅用于虚构演示账号，保存在当前浏览器中，与 HTML 原型的数据独立。数量保存中按已确认金额统计；操作结果不明确时，可在商品项或操作提示处确认结果。撤销记录仅保留在当前应用会话，整页刷新后不保留撤销入口。模拟地址也仅用于虚构信息，单独保存在本浏览器；新增、编辑、删除或默认设置明确失败时可重试；新增/编辑重试使用当前表单输入，默认设置重试原目标。结果未知时先确认原操作，写入已成功而列表读取失败时只重新读取列表；编辑冲突时保留输入，明确重新载入后再修改，读取失败仍会显示反馈。未保存输入与操作标记不承诺跨整页刷新恢复。API 模式当前仅接入公开商品查询，私有购物车、地址、结算与订单接口需配合认证接入。

模拟订单与购物车一并本地保存；读取失败时不会用旧缓存覆盖存储。已确认的提交/取消可恢复原结果，结果未知时通过页面提示确认原操作；操作标记不承诺跨整页刷新恢复。已保存订单可从“我的订单”查询。

开发服务将 /api 请求代理至 http://127.0.0.1:8080。接口结构见 [OpenAPI](../docs/openapi.json)。

## 目录

| 目录 | 内容 |
| --- | --- |
| src | 页面、组件、样式与数据访问代码 |
| assets | 原始图片素材 |
| demo | HTML 交互原型与导出脚本 |
| scripts | 静态资源同步脚本 |
| public | 开发与构建使用的静态资源 |

开发和构建前会自动将商品图片及交互原型同步到 public/images 和 public/prototype。
