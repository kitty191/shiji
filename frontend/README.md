# 拾集前端

基于 React、TypeScript、Vite 和 React Router 构建的桌面端商城界面。

提供商品浏览、搜索、分类与价格筛选、排序、分页和快捷工具栏。商品卡片进入正式详情页，可查看图集、切换规格、调整数量并查看价格库存；刷新保留选择，返回列表保留条件与浏览位置。详情支持加入模拟购物车，右侧摘要按店铺展示原规格、数量与可购商品金额，页面间共享并在刷新后恢复。摘要中的“查看购物车”进入独立页面，支持按项、按店和全选可购商品，显示已选项数、件数、店数及金额；支持数量加减、库存不足时明确调低数量、单项和已选商品删除，以及 8 秒内撤销最近一次删除。数量为 1 时再减会删除该项。勾选在当前应用会话内保留，整页刷新后重新默认选中可购商品。头像菜单的“收货地址”进入正式地址页，可查看、新增与编辑虚构地址；编辑时回显原内容，保存更新同一条地址并保留默认状态。首条自动默认，后续新增可勾选切换默认；未保存输入离开前会提示。店铺及其他账号入口仍打开随附的 HTML 交互原型，购买结算暂未开放。

## 本地运行

在 frontend 目录执行：

```bash
npm ci
npm run dev
```

访问 [本地预览](http://127.0.0.1:5173/#/buyer)。Node.js 版本要求见 [package.json](package.json)。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| npm run dev | 启动开发服务 |
| npm run build | TypeScript 检查与生产构建 |
| npm test | 运行商品查询、SKU、库存、购物车与地址测试 |
| npm run preview | 预览生产构建 |

## 数据配置

默认使用本地模拟数据。将 [.env.example](.env.example) 复制为 .env.local 后，可以调整：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| VITE_DATA_SOURCE | mock | 设置为 api 时请求商品查询接口；购物车与地址暂不可用 |
| VITE_API_BASE_URL | /api/v1 | API 请求地址前缀 |

模拟购物车仅用于虚构演示账号，保存在当前浏览器中，与 HTML 原型的数据独立。数量保存中按已确认金额统计；操作结果不明确时，可在商品项或操作提示处确认结果。撤销记录仅保留在当前应用会话，整页刷新后不保留撤销入口。模拟地址也仅用于虚构信息，单独保存在本浏览器；新增或编辑结果待确认时，应先确认原操作再继续保存；编辑冲突时保留输入，明确重新载入后再修改。未保存输入与操作标记不承诺跨整页刷新恢复。API 模式当前仅接入公开商品查询，私有购物车与地址接口需配合认证接入。

开发服务将 /api 请求代理至 http://127.0.0.1:8080。接口结构见 [OpenAPI](../docs/openapi.json)。

## 目录

| 目录 | 内容 |
| --- | --- |
| src | 页面、组件、样式与数据访问代码 |
| assets | 原始图片素材 |
| demo | HTML 交互原型与导出脚本 |
| scripts | 静态资源同步脚本 |
| public | 开发与构建使用的静态资源 |

开发和构建前会自动将商品图片及交互原型同步到 public/images 和 public/prototype。
