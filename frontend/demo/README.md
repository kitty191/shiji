在项目根目录运行以下命令（需要 Python 3）：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory frontend/demo
```

然后在同一台电脑的浏览器地址栏输入 `http://127.0.0.1:8765/`。终端服务需保持运行，按 Ctrl+C 停止；这是本机地址，其他设备不能用它访问。

页面地址使用 `#/buyer`、`#/detail?...` 等片段，支持后退、前进和刷新恢复页面、筛选、页码与选中图片/规格。未保存的商品编辑在离开时提示；刷新不保存临时表单。订单、自建商品和其他业务记录仍依赖当前浏览器的本地快照，地址不是授权机制，也不提供跨设备数据分享。

商品详情的购买数量只通过左右「− / +」按钮调整，中间只读显示，不显示上下箭头；保留最少 1 件、最多 99 件和当前规格库存限制。

首页和店铺页的四个排序按钮统一为 84 × 34 px，文字居中；可用空间不足时整项换行。

详情加购与立即购买、个人资料保存与取消共用 112 × 40 px；订单六个状态按钮与排序共用 84 × 34 px。各组按钮文字居中、空间不足时整项换行。

此副本不自动同步会话内的演示账号状态；本地状态仍受浏览器保存机制与快照大小限制。已执行的具体浏览器检查见 [原型进度](../../docs/09-原型进度与文档维护.md)。

原型源文件为 [source.html](source.html)，浏览器导航适配为 [browser-navigation.js](browser-navigation.js)；[template.html](template.html) 保存独立预览所需的包装模板。修改后在项目根目录重新导出：

